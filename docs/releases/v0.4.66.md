# Elesis v0.4.66

- Adds Godot-native idle and sword-attack animation support to every Elesis combat form, with a 2D fallback when no local rig is available.
- Makes Strike trigger the sword animation and use the slash hit effect.
- Adds a reproducible local Blender/MMD Tools conversion pipeline for the supplied TDA Empire Sword model.
- Keeps the source and converted model out of Git and public releases because its bundled terms prohibit redistribution of edited models.
