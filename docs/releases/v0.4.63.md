# Elesis v0.4.63

- Adds a dedicated 64×64 packed icon and 256×256 large icon for every Elesis Power.
- Replaces the shared fallback Power artwork with automatic icon lookup derived from each Power ID.
- Fixes dynamic Power descriptions by using the runtime-supported `{Amount}` localization variable.
- Makes the player-facing Sealed Counter status visible in the combat Power row.
- Keeps Answered Attack hidden because it is an internal Counter history marker.
- Normalizes Burn and Counter Attack packed icons to the current 64×64 BaseLib convention.
