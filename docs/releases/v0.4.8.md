# Elesis v0.4.8

Merchant scene stability fix.

- Reworked the Elesis merchant scene root from a bare `Sprite2D` to a neutral `Node2D` with a `Visuals` child.
- Added a minimal `AnimationPlayer` to the merchant scene so BaseLib handles merchant animation calls without falling back to vanilla Spine playback.
- Documented the merchant scene constraint in the architecture notes.
