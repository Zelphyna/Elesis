# Elesis v0.4.31

- Deferred Elesis specialization and evolution events until map or act navigation resumes, so combat rewards can be collected without interruption.
- Prevented duplicate specialization/evolution event openings with pending threshold flags and an in-flight guard.
- Added an act-entry progression check so boss XP thresholds can open after the next act loads.
- Moved the specialization choice event portrait to a dedicated left-positioned canvas so Elesis no longer covers the choice options.
