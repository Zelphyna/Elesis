# Elesis v0.4.57

- Migrates the mod manifest dependency format to the current STS2 character template shape with a BaseLib `min_version`.
- Raises the manifest minimum game version to `0.107.0` and BaseLib minimum version to the resolved current package version.
- Adds the template-derived build target that keeps the manifest BaseLib `min_version` aligned with the resolved NuGet package version.
- Removes the obsolete manual `ModelDbCustomCharacters.Register` call, which no longer exists in current BaseLib.
- Documents the confirmed STS2 `v0.103.2` vanilla card-pool baseline and the current Elesis card-count gap for future card-design passes.
