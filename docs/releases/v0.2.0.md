# Elesis v0.2.0

Prototype gameplay update.

- Added a 40-card Elesis prototype card pool.
- Added Chivalry as a visible counter power.
- Added Flame as a visible counter power.
- Vitality cards build Chivalry and can spend it to draw.
- Destruction cards spend Chivalry for bonus output.
- Flame cards build Flame; non-Flame attacks consume Flame for bonus damage.
- Added design documentation for the current card pool and mechanics.
