# Elesis v0.4.21

- Adds Belder Knight Emblem run experience, gained after completed map nodes.
- Opens a special Elesis specialization event at 15 experience.
- Adds Saber Knight, Pyro Knight, Dark Knight, and Soar Knight specialization choices with run-long relic effects.
- Swaps Elesis' combat visual to the selected specialization for the rest of the run.
- Adds specialization artwork, combat scenes, localization, and design documentation.
