# Elesis Art References

Store visual references here for the Elesis mod art direction.

Use this folder for:
- style references
- pose references
- color and rendering references
- UI or sprite proportion references

Do not use this folder for final in-game assets. Final mod assets should stay under `Elesis/images/` or the relevant `Elesis/scenes/` path.

When adding references, prefer descriptive filenames such as:
- `combat-style-reference-01.png`
- `selection-button-reference-01.png`
- `slay-the-spire-style-reference-01.png`
- `elesis-pose-reference-01.png`
